# 旅行足迹 Footprint

一个纯静态的旅行足迹网页：用原生 HTML/CSS/JS + Leaflet 在地图上记录行程、城市与交通段，数据保存在浏览器本地的 IndexedDB，刷新不丢失。无需 npm、无需构建、无后端。

> 地图底图（高德瓦片）与 Leaflet 库通过 CDN 加载，**首次使用需联网**。

## 一、怎么打开

**方式 A（最简单）：** 直接**双击 `index.html`**，用浏览器（Chrome / Edge / Firefox）打开即可。
打开后会自动预置一条示例行程「广州—西安」，地图上可看到广州、西安两个城市和一段飞机弧线。

**方式 B（推荐，更稳定）：** 用本地静态服务器打开，避免个别浏览器对 `file://` 下 IndexedDB 的限制（详见第二节）。

**方式 C（在线访问）：** 部署到 GitHub Pages，部署步骤见「第二节补充」。

## 二、本地 http.server 启动方法

进入项目目录后用 Python 启动一个静态服务（任选其一）：

```bash
# 方式 1：Python 3
cd D:\projects\footprint
python -m http.server 8000

# 方式 2：若系统里 python 命令指向 Python 2，用 python3
python3 -m http.server 8000
```

启动后在浏览器访问：

```
http://localhost:8000
```

- 端口 `8000` 可改成任意空闲端口（如 `8080`）。
- 关闭服务：在终端按 `Ctrl + C`。
- 没有 Python 时的替代方案：Node 可用 `npx serve .`；VS Code 可用 Live Server 插件。

## 二·补充、GitHub Pages 部署步骤

1. 在 GitHub 上新建一个仓库（如 `footprint`），把本项目全部文件推上去：

   ```bash
   cd D:\projects\footprint
   git init
   git add .
   git commit -m "init: 旅行足迹静态页"
   git branch -M main
   git remote add origin https://github.com/<你的用户名>/footprint.git
   git push -u origin main
   ```

2. 打开仓库页面 → **Settings** → 左侧 **Pages**；
3. 在 **Build and deployment → Source** 选择 `Deploy from a branch`；
4. Branch 选 `main`、目录选 `/ (root)`，点 **Save**；
5. 等 1–2 分钟，访问 `https://<你的用户名>.github.io/footprint/` 即可在线使用。

> 注意：页面通过 CDN 加载 Leaflet 与高德瓦片，访问时需联网；数据保存在**访问者自己的浏览器** IndexedDB 里，不同浏览器/设备互不相通。

## 三、怎么添加 Trip / 城市 / Leg

1. 点击左侧工具栏「录入」打开抽屉。
2. **新增行程 Trip**：填写标题（必填）、起止日期、备注，点「保存行程」。
   - 选定**开始日期**后，结束日期会自动填入同一天，且不能早于开始日期；仍可手动修改。
3. **新增城市**：
   - 先选「所属行程」（切换行程会清空城市相关残留字段）；
   - 在「城市」搜索框输入关键词（如 `贵阳`、`贵州`），结果按省份分组，选中后自动回填省/地区、城市、经纬度，并填入名称(中文)、清空英文名；
   - 也可选「手动填写」直接输入省、城市、经纬度与名称；
   - 补充到达/离开日期、天气、心情、花费、同行者、备注，点「保存城市」。
4. **新增交通段 Leg**：选行程、出发城市（可先选常驻城市或跨行程城市，也可手动输入）、到达城市、交通方式（✈️ 飞机 / 🚄 高铁动车 / 🚞 普速火车 / 🚌 大巴 / ⛵ 轮船 / 🚗 自驾），填写起止时间与花费，点「保存交通段」。常驻城市可在「设置」抽屉修改。
5. 所有增删改即时写入 IndexedDB，刷新页面数据都还在。

## 四、JSON 导入 / 导出在哪

在「设置」抽屉：

- **导出全部 JSON**：把当前所有 `trips / stops / legs` 打包成 `footprint-backup-日期.json` 下载到本地。
- **从 JSON 导入**：选择之前导出的 JSON 文件，导入会**覆盖**当前全部文字数据（导入前有确认弹窗）。
- **清空全部数据**：点击后会弹出**两次**确认，确认后才真正清空。

> 说明：少数浏览器（尤其部分 Chrome 版本对 `file://`）可能限制 IndexedDB 持久化。若发现刷新后数据丢失，请用第二节的 `http.server` 方式打开即可正常保存。

## 五、示例数据如何清空

- **方式一（整库清空）**：「设置」抽屉 → 点「清空全部数据」→ 两次确认即可。
- **方式二（单条删除）**：在「录入」抽屉的已有数据列表中，点对应行程 / 城市 / 交通段的「删除」按钮（删除行程会级联删除其城市与交通段，删除城市会级联删除相关交通段）。
- 清空后再次打开**不会**重新预置示例数据（示例仅在数据库为空时写入一次）。若想恢复示例，可手动清空后刷新页面（数据为空时会重新写入示例）。

## 六、城市照片说明

- 入口：地图上点击城市弹窗里的「📷 照片（n）」按钮，或「录入」抽屉中城市条目的「管理照片」按钮，都会打开该城市的照片抽屉。
- 上传：支持一次多选，仅图片（不做视频）。上传时用 canvas 压缩（长边 1600px、JPEG 质量 0.8）后才入库，不存原图。
- 注释：点缩略图看大图，可编辑拍摄日期（默认当天）、拍摄者（可空）与说明文字；删除需二次确认；可设为/取消「封面」（气泡缩略图）。
- **照片只存在本机浏览器的 IndexedDB 里，JSON 导出/导入不包含照片（仅行程、城市、交通段、点亮状态、日记等文字数据），换设备暂不同步**；「清空全部数据」会连同照片一起清空。

## 七、内置城市坐标表（data/cities.js）

- 覆盖范围：全国**地级市、自治州、盟、地区**（约 370 条），另含直辖市/港澳台省级条目。
- 数据来源：**阿里云 DataV 地市 GeoJSON 中心点（centroid）**，构建脚本批量提取，未凭印象填写任何经纬度。
- 已知缺口：
  - 个别无中心点数据的地市未收录（构建时自动跳过，当前为 0 条跳过）；
  - 直辖市只收录市级单条（不含下属区县），台湾省仅收录省级条目（DataV 台湾子级接口 404）；
  - 未收录的城市可在表单里**手动填写经纬度**，功能完全可用。

## 八、目录结构

```
footprint/
├── index.html          # 页面结构 + Leaflet 1.9.4 CDN（CSS/JS 同版本）
├── css/style.css       # 样式（双主题变量、响应式）
├── js/db.js            # IndexedDB 封装（增删改、导入导出、清空）
├── js/app.js           # 地图 / 时间线 / 表单 / 设置 / 主题 / 照片
├── data/china-provinces.js  # 全国省界 GeoJSON（内嵌）
├── data/cities.js      # 全国城市坐标表（DataV 中心点）
└── README.md
```
